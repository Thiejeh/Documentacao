# app-blog

Sistema de blog com area publica e painel administrativo.

## Tecnologias
- PHP 8
- MySQL
- HTML e CSS

## Funcionalidades
- Font-end: listar e ler postagens
- Painel admin: login, criar, editar e excluir postagens

## Como Exacutar
1. Instale o XAMPP e inicie o Apahe eo MySQL
2. Copie a pasta app-blog para hitdocs
3. Importe o arquivo banco/app_blog sql no phpMyAdmin
4. Acesse http://localhost/app-blog

## Estrutura de pastas
- /admin: painel administrativo
- /public: paginas do front-end
- /includes: conexão com o banco e funções
- /banco: script SQL
- /docs: documentação
